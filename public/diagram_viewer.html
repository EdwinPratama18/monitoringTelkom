3. Class Diagram Architecture & MVC

Struktur arsitektur model Eloquent Laravel, atribut, method relasi database, dan interaksi controller.

Download PNG (240 DPI) Download SVG Vektor

Entitas & Model Relasional:

  • User: Model akun dengan relasi hasMany(Maintenance::class, 'teknisi_id').
  • Perangkat: Model perangkat infrastruktur dengan relasi hasMany(Maintenance::class, 'perangkat_id').
  • Maintenance: Model tiket pemeliharaan dengan foreign keys ke User dan Perangkat, dilengkapi atribut JSON checklist dan path eviden.

5. Entity Relationship Diagram (ERD) Database Schema

Skema basis data fisik MySQL dengan tipe data, primary key, foreign key, dan integritas relasional.

Download PNG (240 DPI) Download SVG Vektor

Struktur Relasi Basis Data (ERD Bersih):

  • users (1) → maintenance (N): Relasi penugasan teknisi/admin pada kegiatan pemeliharaan (FK: user_id → users.id, ON DELETE CASCADE).
  • perangkat (1) → maintenance (N): Relasi riwayat pemeliharaan pada masing-masing unit perangkat STO (FK: perangkat_id → perangkat.id, ON DELETE CASCADE).
